# 🤖 Discord MemeBot

A lightweight **Python-based Discord bot** that integrates with an external REST API to fetch and deliver random memes directly within Discord channels.

## ✨ Features

* Fetches random memes dynamically through a REST API
* Responds to user commands in real time
* Integrates with the Discord API using `discord.py`
* Securely manages credentials using environment variables

## 🛠 Tech Stack

**Python • Discord.py • REST API • Requests • JSON • python-dotenv**

## 🚀 Commands

* `$meme` — Fetches and sends a random meme
* `$hello` — Sends a simple greeting response

